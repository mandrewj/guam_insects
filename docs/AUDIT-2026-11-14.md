# Audit of 2026-11-14: what was done, and what needs a decision

Six read-only subagents audited performance, accessibility, documentation, data structures,
the code, and possible features. Their reports are model output; the safe items were
implemented (commits "Audit round 1/2"), the rest is below for review.

## Done
- Docs: CLAUDE.md (history note, command list), README (getting started), APP_SPEC, LESSONS,
  REFACTOR, STATUS, docstrings, `.gitignore`, sync-records skill.
- Performance: layout shift on every page (reserved `main#app` height), search names preload on
  focus, image size/priority hints.
- Accessibility: header focus rings, dark-mode chip contrast, lightbox focus trap and inert
  background, 24 px targets, editor focus ring and dark-mode contrast.
- Data: *Hermetia illucens* nativity reset to unknown (machine value "native" with source
  "gbif"); `utm_` parameters stripped from 593 Commons URLs.

## Decisions needed
**Data**
1. 838 visible species (Diptera 373, Coleoptera 190, Hemiptera 121) have no records,
   literature or distribution row: they came from `review/unplaced` rows keyed by opaque
   numeric ids, so the source document was lost. Recover document and pages from
   `data.nosync/guam-pipeline-v1.sqlite`, or hide those that cannot be recovered?
2. Duplicates: *Alphitobius diaperinus* is twice (IOG-3 yours, LJGG5 from COL); 95 pairs share
   family, epithet and authorship (e.g. *Mycerinopsis*/*Sybra*); 16 species pairs share a photo;
   124 synonyms in names.csv are another taxon's accepted name. Each merge is your call. Also
   proposed: a check for duplicate accepted names, and a name lookup in the editor's Add tool.
3. Nativity: 6,307 of 6,343 accepted taxa unknown. Does nativity apply above species (7 genera
   carry "native")? Fill from documents via `/ingest-literature` (UOG fact sheets, crop pests).
4. 1,146 literature rows have empty `areas`, so they add no presence. Swezey 1942 covers
   Guam only: fill GU for its 62 rows?
5. Placement: same genus under two families (*Lepidosaphes*, *Cyrtorhinus*, *Bostrichus*);
   36 families and 281 genera without species.
6. Sort order of taxa.csv (depth-first by name moves whole subtrees in diffs) versus by id.
7. Non-hexapods in the unplaced list (*Achatina*, plants): exclude them? 41 documents have no
   citing rows (incl. the arachnid IOM volumes); 25 document file paths no longer resolve.
8. Three placeholder citations (kulzer-1957, bremer-2004, bremer-2014) back 18 of 27 tags.

**Not yet implemented (safe, but larger)**: new `dataset check` rules (date validity, name
shape versus rank, enums for iucn/licence, island names versus geo, presence required for
visible species); deriving `literature.islands` from `islands.csv`; splitting hosts into
common and scientific names; editor keyboard access (taxon list, table grid, tab roles,
alert roles); presence-table `scope` attributes; region chips as real buttons; heading order.

**Performance (your call)**: immutable caching of `data/*` with a `?v=` build stamp (edit
`ops/deploy.sh`); local thumbnails for every photo (~35 MB) or `medium.jpg` for hero images;
split `names.js` (251 KB brotli cold) while keeping tokenizer parity; paginate or batch the
Identify view on large groups (~10,000 nodes).

**Accessibility (appearance)**: map dots/labels for unrecorded islands are below 3:1;
editor input borders are 1.3:1.

**Features**: nothing built before nativity coverage improves. Cheap candidates:
meta description/OpenGraph, a `#/new` recently-added page, an "unverified" badge on species
pages, shareable filtered views, a how-to-cite/report-an-error link. Wording check: the
landing page says beetles are the group being checked by hand (app.js, About).
